Automate Everything via Local REST API

Adsclin runs a high-performance local HTTP server on http://127.0.0.1:3001. Connect your Python, Node.js, or Go scripts with ease.

  • ➔ POST /api/v1/profiles/:id/start — Starts browser & returns CDP endpoint
  • ➔ POST /api/v1/profiles/:id/stop — Clean session teardown
  • ➔ GET /api/v1/profiles/active — List all currently running instances
launch-profile.py Python + Playwright 
import requests
from playwright.sync_api import sync_playwright

# 1. Launch profile via Adsclin Local API
res = requests.post(
  "http://127.0.0.1:3001/api/v1/profiles/p-101/start",
  headers={"X-API-Key": "your_api_token"}
).json()

# 2. Connect Playwright to the active browser
with sync_playwright() as p:
  browser = p.chromium.connect_over_cdp(res["wsEndpoint"])
  page = browser.contexts[0].new_page()
  page.goto("https://pixelscan.net")
  print("Stealth status:", page.title())
